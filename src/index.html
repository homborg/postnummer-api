📍 Postal Code Lookup API

Get postal codes from coordinates worldwide

📖 API Documentation (OpenAPI/Swagger)

Usage

GET /lookup?lat={latitude}&lng={longitude}

Examples

  • 🇩🇰 Copenhagen, Denmark 🗺️ (local)
  • 🇩🇪 Berlin, Germany 🗺️
  • 🇫🇷 Paris, France 🗺️
  • 🇺🇸 New York, USA 🗺️
  • 🇮🇳 Mumbai, India 🗺️
  • 🇿🇦 Johannesburg, South Africa 🗺️
  • 🇵🇪 Lima, Peru 🗺️

Response

{
  "postalCode": "1550",
  "city": "København V",
  "country": "Denmark",
  "source": "local",
  "mapUrl": "https://www.google.com/maps/search/..."
}

Denmark uses local polygon data. Other countries use OpenStreetMap Nominatim with caching.
